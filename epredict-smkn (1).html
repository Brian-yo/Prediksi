Tentang sistem
prediksi ini

EduPredict SMKN Pasirian adalah sistem prediksi kelulusan siswa berbasis JavaScript murni yang berjalan sepenuhnya di browser — tanpa server Java, Python, atau koneksi internet.

Model menggunakan weighted scoring dengan empat komponen akademik. Skor gabungan dibandingkan dengan ambang batas kelulusan untuk menghasilkan prediksi beserta tingkat keyakinan.

Arsitektur ini memastikan sistem dapat berjalan offline, cepat, dan mudah di-deploy hanya dengan satu file HTML.

Vanilla JS Weighted Scoring Pure HTML/CSS Offline Ready
// Fungsi prediksi JavaScript
function predict(n, h, t, u) {
  var score = n*0.30 + h*0.25
           + t*0.20 + u*0.25;
  var lulus = score >= 60;
  var conf = calcConf(score, lulus);
  return { lulus, score, conf };
}

Fitur input
model prediksi

  • nilai_rata — bobot 30%
    Nilai rata-rata seluruh mata pelajaran semester berjalan
  • kehadiran — bobot 25%
    Persentase kehadiran siswa (0–100%). Di bawah 75% otomatis diklasifikasikan berisiko
  • tugas — bobot 20%
    Jumlah atau persentase tugas yang diselesaikan
  • ujian — bobot 25%
    Nilai ujian akhir semester sebagai faktor kritis
Output Model

lulus → true/false — hasil klasifikasi
score → skor gabungan berbobot (0–100)
confidence → tingkat keyakinan berdasarkan jarak dari ambang batas
rekomendasi → saran intervensi spesifik per komponen lemah
